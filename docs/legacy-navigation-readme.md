# UniCars navigation prototype

Interactive static prototype of the proposed navbar, footer and contextual mobile actions. Toggle the old shortcut rail for comparison. Use Mobile preview to inspect the responsive menu and action bars.

The prototype uses supplied brand assets. Vehicle and location content is illustrative. Forms perform local demonstration only; they do not submit requests or persist personal details.

Serve the dist directory as a static site. No build step or dependencies are required.

## Navigation refinement November 2026

Retains Support as a primary navigation item and groups ownership tasks separately from service and repairs. Sales contains the five passenger-car brands, model categories, prices, offers and financing. Available Cars is the catalogue entry point. For EVs separates vehicle research from charging; Visit Us includes city routes. Price lists and service booking also have persistent utility shortcuts.

The reference's large image is reduced to 26% of each desktop mega menu. Figtree and Archivo typography, clear group labels, a compact close control and a primary action replace repeated icon cards and decorative counters. Desktop supports intentional mouse hover, clicks, Arrow Down entry, Escape dismissal and focus-out dismissal. At 1100px the navigation becomes an accordion sheet, with prices and service booking first. Reduced-motion preferences are respected.

Verified in the managed browser at desktop, 768px and 390px: no horizontal overflow, pricing destination, EV menu, location preselection, service-booking demonstration dialog, keyboard entry and Escape, mobile accordion and mobile service action. Business destination pages remain illustrative and forms do not transmit requests. The uploaded reference was inspected but not modified. No live Unicars site was changed.
